# Publicar LEORI CONSULTING en GitHub Pages

1. Crea en GitHub un repositorio público llamado `leori-consulting`.
2. En el repositorio, pulsa **Add file → Upload files**.
3. Descomprime el ZIP y sube **el contenido de la carpeta**, no la carpeta completa:
   - `index.html`
   - `styles.css`
   - `.nojekyll`
   - `assets/`
4. Confirma con **Commit changes**.
5. Ve a **Settings → Pages**.
6. En **Source**, selecciona **Deploy from a branch**.
7. Selecciona la rama `main`, la carpeta `/(root)` y pulsa **Save**.

La dirección esperada será:

`https://michel1n0.github.io/leori-consulting/`

Si GitHub no muestra `.nojekyll` en el selector de archivos, no hay problema: la web es HTML estático y puede funcionar sin él.
